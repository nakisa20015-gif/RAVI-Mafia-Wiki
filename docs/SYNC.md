# سیاست همگام‌سازی RAVI Wiki

ویکی اصلی RAVI مرجع نهایی است. این مخزن فقط محتوای عمومی نقش‌ها و سناریوها را منتشر می‌کند.

**وضعیت: همگام‌سازی خودکار هنوز فعال نشده است.** برای خودکارسازی باید منبع عمومی داده‌های Wiki و روش امن دریافت تغییرات مشخص شود. هیچ کد خصوصی یا اطلاعات کاربران نباید در این مخزن کپی شود.
